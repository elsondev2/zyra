## Package gate and boundary note

`npm run release:package -- --dir=true --skip-build=true` was started because the release prompt described non-installing package validation. The command internally ran an npm install in `desktop/.release/zyra-runtime` and then began `dotnet publish` restore. This crossed the no-install boundary and was stopped immediately; the remaining attributable restore process tree was terminated. No installer was executed and no PATH, account, credential, Browser data, signing state, tag, updater, or public release was changed.

The partial ignored staging tree is not candidate evidence. No complete unpacked app, upgraded Desktop dependency proof, installer, or cold-launch result was produced.
